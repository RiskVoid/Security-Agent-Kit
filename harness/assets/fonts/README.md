# Fonts

Latin subsets (woff2) of the RiskVoid brand fonts, used by the console and embedded in the HTML report so neither
fetches anything from the internet. All three are under the SIL Open Font License 1.1.

| File | Family | Source |
|---|---|---|
| `inter-latin.woff2` | Inter (variable, 100–900) | rsms/inter, via Google Fonts |
| `jetbrains-mono-latin.woff2` | JetBrains Mono (variable, 100–800) | JetBrains/JetBrainsMono, via Google Fonts |
| `space-grotesk-latin.woff2` | Space Grotesk (variable, 300–700) | floriankarsten/space-grotesk, via Google Fonts |
