Under the hood

A full agent harness.

Not a prompt wrapped around a shell. Most of the kit is the machinery around the model.

Delegation

Focused tasks

The worker gets one goal and returns a redacted summary. Raw output never reaches the planner.

Policy

Scope compiled into policy

SCOPE.md and RULES.md become versioned policy. A line the kit can't enforce is an error.

Approvals

Exact-action approvals

Bound to a digest of the command, its inputs and the policy revision. Used once.

Isolation

A sandbox per command

Own namespaces, an unprivileged user, and only the credentials the command names.

Model gateway

Data routes enforced

An offline engagement can't reach a cloud model, whatever the conversation asks.

Durability

Survives a restart

Tasks resume from a checkpoint. An in-flight write is flagged, not repeated.

Resilience

Refusals handled

A refused or empty reply is retried or answered by a fallback model.

Findings

Verified findings only

A candidate is confirmed only when the planner states how it was verified.

FAQ

Common questions.

Do I need a GPU?

No. A computer with Docker and an OpenRouter key is enough. If you have a GPU, the worker can run there instead.

What does it cost to run?

The kit is free. You pay for model usage: $0.52 to $3.13 per run in the first benchmarks, under a daily cap.

Does client code leave my machine?

Your choice. Only the worker model reads source code, and you decide where it runs. With a local worker and an offline engagement, nothing leaves your machine.

Does it replace a penetration tester?

No. It does the routine work and keeps the record. A person sets the scope, approves the risky steps and signs off the report.

Can I put my own brand on the report?

Yes. Reports come in RiskVoid branding or a plain brand with your organisation's name.

Is the licence going to change?

The kit is Apache-2.0 with no paid edition. RiskVoid's commercial product is a separate hosted GitHub App.

Can I use it in CI?

Not as a packaged step yet. Findings export as SARIF today; a GitHub Action is on the roadmap.

Is it legal to use?

Only on systems you own or have written permission to test. The controls keep a run inside its scope; the authorisation is yours to get.

How do I report a security issue in the kit?

Privately, as described in SECURITY.md in the repository.

Try it on the lab first.

An isolated practice lab is included. One guided run takes about 20 minutes.
